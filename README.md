# Car Price Prediction 🚗

A Machine Learning project that predicts the price of a car based on different features.

## 📌 Project Overview

This project uses Machine Learning regression techniques to predict car prices from features such as:

* Car Model
* Year
* Transmission
* Mileage
* Fuel Type
* Tax
* MPG
* Engine Size

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Streamlit
* Joblib

## 🤖 Machine Learning

The project includes:

* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Encoding
* Feature Scaling
* Model Training
* Model Evaluation
* Price Prediction

## 📊 Input Features

| Feature      | Description          |
| ------------ | -------------------- |
| model        | Car model            |
| year         | Manufacturing year   |
| transmission | Type of transmission |
| mileage      | Car mileage          |
| fuelType     | Fuel type            |
| tax          | Vehicle tax          |
| mpg          | Miles per gallon     |
| engineSize   | Engine size          |

## 🚀 How to Run

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn streamlit joblib
```

Run the Streamlit application:

```bash
streamlit run app.py
```
